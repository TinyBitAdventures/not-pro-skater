# Skate Park

An isometric, Tony-Hawk-flavoured skateboarding game. Cruise a sunny community park, link ramps, rails and manuals into big combos, and beat your best two-minute score. The look is a chunky low-poly cartoon: flat colours, three-band shading and inked outlines.

Built with **Blender** (every model is generated by a script) and **Godot 4.7** (GDScript). It uses the Compatibility renderer, so the same project exports to the **web** as well as desktop.

> Working title. Prototype: one level, one rider.

## Play

Open `game/` in Godot 4.7.2 and press F5, or from a shell:

```bash
cd game
godot --path .
```

Two steering styles (toggle with T, or in the title menu; both are saved):

- **Skater steering** (default): W pushes, S brakes, A / D turn relative to the skater, like a classic skate game. With **camera: follow** (default) the camera swings to keep the skater riding up the screen, so left is always the skater's left. C toggles a **fixed** isometric camera.
- **Screen steering**: the stick points where you want to go on screen.

| Key / pad | Action |
|-----------|--------|
| W / S, stick up / down | Push / brake (skater steering) |
| A / D, stick left / right | Turn (skater steering) |
| Space / A | Ollie |
| J / X | Flip (steer for variations) |
| K / B | Hold to grab (steer for variations) |
| L / Y | Grind: press near a rail, ledge or coping |
| M / RT | Manual (flat ground) |
| Shift / LT | Brake |
| A / D in the air | Spin (then J or K for tricks) |
| Q / E | Turn the camera in 90 degree steps |
| C | Camera follow / fixed |
| T | Steering skater / screen |
| R | Reset to the start |
| N | Music on / off |
| Esc | Pause |

Combos: every trick adds points and, if it is new to the combo, one to the multiplier. Land cleanly and keep going within about a second; stop and the combo is banked. Bail and you lose it.

## Build the assets

The game reads two glTF files that Blender generates from scripts.

```bash
./build.sh            # blender --background ... then godot --headless --import
./build.sh park       # just the level
./build.sh skater     # just the rider
```

Needs Blender 5.2 and Godot 4.7.2 on your `PATH`. Godot does not re-import a changed glTF on its own; `build.sh` runs the import for you.

### Pipeline conventions

- Blender is Z-up, models face `+Y`; Godot sees `(x, z, -y)`.
- Materials are flat colours. Godot swaps every material for the toon shader at load time; the Blender material **name** picks the style (`game/scripts/util/toon.gd`).
- An object named `Wood_QuarterPipe_01-col` is visible **and** collidable; `..-colonly` is collision only. The part before the first underscore is the surface type the skater feels (`Grass`, `Path`, `Plaza`, `Concrete`, `Wood`, `Metal`, `Wall`).
- `Grind_<id>_<n>` empties are numbered points of a grindable line.
- `Spawn_Player`, `Pickup_<letter>_<n>` and `Text_<WORDS>_<n>` empties place the spawn, letter pickups and banner lettering.
- The level is baked at load: every static mesh is merged per material per map cell (`level_baker.gd`), so hundreds of props cost a few dozen draw calls.

### Adding a piece or a level

Pieces live in `blender/pieces.py` (each takes a root empty and builds in local space: `+Y` is the ride direction). `blender/park.py` places them (`place("quarter_pipe", x, y, rot_deg, ...)`). A new level is another script next to `park.py` that calls `build()`, plus a `Level` load in Godot.

## Tests

```bash
cd game
godot --headless --import --path .
TEST=flat  godot --headless --path . res://scenes/dev_skate.tscn   # also ramp, grind, bail, bailclear, lap
SHOTS=poses godot --path . res://scenes/dev_shots.tscn --resolution 1600x900   # gameplay screenshots -> ../shots
godot --path . res://scenes/dev_view.tscn --resolution 1600x900                 # level tour -> ../shots
godot --path . res://scenes/dev_perf.tscn --resolution 1600x900                 # fps + draw calls
```

Dev scenes never touch your real save (`Game.is_dev_run()`).

## Web build

Templates for 4.7.2 (`web_nothreads_release.zip`) must be installed. Then:

```bash
cd game
godot --headless --export-release "Web" ../build/web/index.html
cd ../build/web && python3 -m http.server 8060
```

The preset is single-threaded, so no cross-origin-isolation headers are needed and any static host works. Serve `index.wasm` compressed (gzip or brotli: 39 MB raw).

## Layout

```
blender/   lib.py (mesh helpers) pieces.py (kit) park.py (level) skater.py (rider) build.py
game/
  scripts/skater/   Skater (physics + states), SkaterVisual (IK rig), ScoreKeeper, Tricks, SkaterBrain (AI)
  scripts/level/    Level (glTF loader), LevelBaker (mesh merging)
  scripts/camera/   IsoCamera
  scripts/park/     ParkWorld (session), TitleScreen, WorldEnv (sun/sky)
  scripts/ui/       Hud, UiKit
  scripts/autoload/ Controls (input map), Game (settings, saves), Sound
  scripts/util/     Toon (materials, outline normals)
  shaders/          toon, outline, fence, blob, occlude
audio/     build_sfx.py build_music.py (numpy placeholders)
```
